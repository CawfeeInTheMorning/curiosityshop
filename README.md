This website is the amalgamation of a few ideas, those mainly being to record all of the possible soul values in the Valve made game Deadlock. It's also to create a free-use space for people to experiment with item values, as well as a searchable interface for comparing character stats, and item stats mathmatically updating as the user changes options, both real and theoretical.
